# Servicio web de EasyAccounting

## Descripción
Este proyecto consiste en el desarrollo de un servicio web para el sistema EasyAccounting, utilizando Node.js y JavaScript.

## Funcionalidades
- Registro de usuarios.
- Inicio de sesión.
- Validación de credenciales.
- Respuestas del servidor en formato JSON.

## Tecnologías utilizadas
- Node.js
- JavaScript
- Visual Studio Code
- Git y GitHub

## Ejecución
Para iniciar el servicio web, ejecutar el siguiente comando en la terminal:

`node server.js`

El servidor utiliza la dirección:

`http://localhost:3000`
